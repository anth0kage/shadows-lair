1. Quête : page LinkedIn BuildGreen Analytics + connexion Postiz

Quête secondaire · tableau : général · id : t_3ef03bbd

QUÊTE — Créer la page LinkedIn de BuildGreen Analytics et la connecter à Postiz.

Prérequis : le kit visuel de Kaisel doit être prêt dans ~/lair-sites/buildgreen/kit/ (tâche t_d40ff293).

## Action 1 : Créer la page LinkedIn
- Se connecter sur https://www.linkedin.com/
- Aller dans Pages → Créer une page
- Nom : BuildGreen Analytics
- URL : linkedin.com/company/buildgreen-analytics (ou similaire)
- Secteur : Services environnementaux / Développement de logiciels
- Description : Scoring énergétique B2B pour prioriser les rénovations et garantir la conformité réglementaire. Données BDNB/CSTB sous Licence Ouverte v2.
- Logo : utiliser le logo du kit Kaisel (~/lair-sites/buildgreen/kit/logo.svg)
- Bannière : utiliser les visuels du kit

## Action 2 : Connecter à Postiz
- Se connecter sur Postiz
- Ajouter le compte LinkedIn dans Social Accounts
- Suivre le flux OAuth pour autoriser Postiz à publier sur la page
- Une fois connecté, vérifier que le compte apparaît bien dans Postiz

## Action 3 : Noter les accès
- Stocker les identifiants LinkedIn dans le coffre :
  `lair-vault-ajout "linkedin-buildgreen" "URL de la page + email admin"`
- Mettre à jour la fiche produit (~/.hermes/lair/produits/buildgreen/FICHE.md) avec le nom du compte LinkedIn

Une fois terminé, commenter cette tâche avec « FAIT » et l'URL de la page.
